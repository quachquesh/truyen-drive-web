# Chọn kho truyện trực tiếp từ Drive (browser folder trong app)

## Hướng chọn
**Không dùng Google Picker API** — nó yêu cầu tạo thêm API key (Developer Key) trên Google Cloud Console. Thay vào đó tự build browser folder ngay trong app, tái dùng token + scope `drive.readonly` + `files.list` như mọi chỗ khác (Viewer-only vẫn chạy tốt).

2 điểm khởi đầu:
- **☁️ My Drive** — `listChildren('root')` lọc folder client-side (giống FolderPage)
- **👥 Đã chia sẻ với tôi** — query mới `sharedWithMe = true and mimeType = folder and trashed = false` (kho của bạn là folder được share → nằm ở đây)

Giữ ô **dán URL/ID** làm phương án dự phòng (folder share link-only không hiện trong sharedWithMe).

## Files thay đổi

### 1. `src/lib/driveApi.ts` — thêm 1 hàm
```ts
export async function listSharedFolders(options: { signal?: AbortSignal } = {}): Promise<DriveItem[]>
```
Paginate `/files` với `q: "sharedWithMe = true and mimeType = 'application/vnd.google-apps.folder' and trashed = false"`, `fields: 'nextPageToken, files(id, name, mimeType)'`, pageSize 1000, kèm `supportsAllDrives: true, includeItemsFromSharedDrives: true` (phòng khi là shared drive).

### 2. MỚI `src/components/DriveFolderPicker.vue`
- Emit `select(folder: { id: string; name: string })`
- View gốc: 2 hàng ảo "☁️ My Drive" / "👥 Đã chia sẻ với tôi". Click → load danh sách folder con (home: `listChildren('root')` lọc folder; shared: `listSharedFolders()`), `naturalSort` theo tên
- Click folder con → vào sâu (stack breadcrumb), ← Trở về để pop
- Thanh trên: ← Trở về (khi depth > 0) + tên folder hiện tại + **"✓ Chọn folder này"** (primary, disabled ở 2 view gốc ảo)
- UI theo pattern FolderPage: hàng folder = NButton quaternary block align-left "📁 tên", NSpin khi tải, NEmpty khi rỗng, NAlert lỗi + thử lại; list max-height ~300px overflow auto

### 3. `src/components/LibraryModal.vue` — thay section "Thêm kho"
- Mặc định hiện `<DriveFolderPicker @select="onPick" />`; `onPick({id, name})` → đặt `newName = name`, `newFolder = id` → gọi `addLibrary()` ngay (tên kho = tên folder; đổi tên sau bằng ✏️; `libraryStore.add` vẫn validate bằng `listChildren` như cũ)
- Link nhỏ "Dán URL / ID thủ công?" → toggle hiện form NInput cũ (giữ nguyên path `parseFolderId`)
- Lỗi hiển thị vào `addError` như hiện tại

### 4. README — cập nhật mô tả thêm kho ("chọn từ Drive hoặc dán URL")

## Kiểm chứng (không dùng browser)
`bun run test:unit` (37 test hiện tại phải xanh — không đổi contract nào) + `bun run lint` + `bun run build`. Không thêm test HTTP mới (pattern hiện tại driveApi chỉ test pure function; picker là component-level, chưa có infra test component).

Bạn test: mở "Kho truyện" → thấy My Drive + Đã chia sẻ với tôi → vào shared → bấm vào folder kho → kho được thêm & mở luôn; dán URL vẫn chạy như cũ.
